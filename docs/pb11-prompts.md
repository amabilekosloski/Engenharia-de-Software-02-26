# Prompts de montagem das páginas 3 a 8 — Ecos de Nós

Cada prompt monta **uma página** com 3 quadros, no mesmo layout da página 3.

## Como usar

1. Abra a conversa do ChatGPT onde a página 3 deu certo (ou uma nova).
2. **Anexe 4 imagens:** a `pagina01` (referência de layout e de balões) e os 3 quadros da página, na ordem.
3. Cole o prompt da página.
4. Confira o texto de cada balão e a ordem de leitura. Se algo sair errado, peça o ajuste na mesma conversa.
5. Salve como `pagina03`, `pagina04`... até `pagina08`.

Se o ChatGPT redesenhar os quadros em vez de usar as imagens como estão, monte no Canva.

**Legenda dos balões usada nos prompts**
- Personagens: balão branco arredondado, contorno preto.
- Central: balão azul-claro anguloso, cauda em zigue-zague.
- Narração: caixa retangular branca, borda preta.
